# 协同工作平台前端重构计划

以 figma/src 的本地原型导出为设计依据。Vue 3.4.38、Vite 4.5.14（锁文件）、Element Plus 2.7.8 保持版本；构建在 Node 16.20.2 验证，运行目标为 Win7 上的 Chrome 109 / Chromium 同等内核。

1. 沿用 Keycloak -> RBAC bridge -> admin/index -> handleAdminRoute，客户端与项目标识改为 cooper；仅初始化 cooper 项目菜单，不修改其他项目授权。
2. 移植顶栏、四列双行首页、日历、应用中心、新闻中心、会议/值班、荣誉墙、危险作业与故障子界面。
3. API 使用文档字段及各自响应层级；业务 Mock 默认延迟，身份与权限保持真实服务。新闻/公告净化 HTML。
4. MQTT v3.1.1 刷新新闻/公告；日历 SSE；公告控制器在顶层唯一挂载，以跨标签页租约控制独立 window.open 窗口，直接使用弹窗专用接口的完整公告数组，按 IsTop 置顶后纵向滚动展示，不记录已阅状态。
5. 新闻/公告预览及 Office 全屏预览使用独立静态路由。OnlyOffice 复用远端服务，签名配置须由后端生成。
6. 达梦初始化后回读菜单；真实 SSO/RBAC、Node16 构建、浏览器慢加载及交互检查。未在 Win7 真机执行的检查单独列明。
